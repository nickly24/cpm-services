# HTTP-проверка вложенного результата callback

`scripts/callback_guard_smoke.py` проверяет только завершённое собственное B2-задание `2c3ae817-0008-4c39-8a40-68de64dcf8a4`, организация `2001`, подразделение `10191`, tenant run `10d3deb9e73c`. Его два аккаунта сверяются с закрытым manifest и текущими точными участиями. Исходные outputs читаются только из собственных строк ratings через SQL SELECT. Задания и источники не создаются и не меняются; управления процессами и очередями нет.

После отдельного подтверждения root о готовности нового validators runtime команда отправляет копии сохранённого результата только на фиксированный `127.0.0.1:8012`, без перенаправлений. Сервисный ключ читается из закрытого `cpm_dev` окружения и не попадает в отчёт.

```sh
dev/.venv/bin/python services/ratings/scripts/callback_guard_smoke.py --allow-callbacks
```

Всё осталось неизменным. Новых заданий, source writes и перезапусков было 0. Заключительный GET readiness подтвердил рабочий ratings с обоими режимами `required`.

# Адаптер снимка Go exams

Ratings использует фактический endpoint текущего Go-сервиса exams. Реализация находится в `internal/ratings/exam_adapter.go`; арифметика рейтинга остаётся в calculate. Наличие кода адаптера не подтверждает подключение конкретного dev/production экземпляра exams.

## HTTP владельца

```text
GET /internal/exams/rating-snapshot
X-Service-Key: значение AUTH_INTERNAL_KEY из окружения
```

Query задаётся через URL encoding:

```text
organization_id=1001
division_ids=1002
date_from=2026-10-01
date_to=2026-10-31
as_of=2026-10-08T07:00:00Z
```

Владелец допускает список подразделений через запятую; ratings запрашивает ровно одно подразделение своего задания. `date_from`/`date_to` — включительные московские календарные даты, `as_of` — закреплённое UTC-время задания. Exams проверяет служебный ключ и ссылки core, затем читает каталог и ревизии в одной MySQL Repeatable Read транзакции.

Успешный ответ имеет общий конверт `{status:true,data:...}`. Фактические DTO владельца — `RatingSnapshotDTO`, `RatingCatalogueEntry`, `RatingResult`, `RatingRevision` в `services/exams/internal/exams/auxiliary.go`:

```json
{
  "status": true,
  "data": {
    "source_revisions": {"1002": 3},
    "snapshot": {
      "source": "exams",
      "organization_id": 1001,
      "division_ids": [1002],
      "date_from": "2026-10-01",
      "date_to": "2026-10-31",
      "as_of": "2026-10-08T07:00:00Z",
      "source_revision": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
      "revisions": [
        {"exam_id": 42, "division_id": 1002, "exam_revision": 2, "division_revision": 3}
      ],
      "next_exam_start_at": null,
      "exams": [
        {
          "exam_id": 42,
          "division_id": 1002,
          "direction_id": 7,
          "exam_type": "classic",
          "exam_date": "2026-10-08",
          "start_at": "2026-10-08T06:00:00Z",
          "exam_revision": 2,
          "division_revision": 3
        }
      ],
      "results": [
        {
          "exam_id": 42,
          "division_id": 1002,
          "account_id": 501,
          "grade": 4,
          "missing_result": false,
          "result_id": 56,
          "attempt_no": 2,
          "has_appeal": true,
          "result_version": 3,
          "history_generation": 1
        }
      ]
    }
  }
}
```

Хеш в примере — условный заполнитель. Настоящий `source_revision` exams считает по массиву `revisions`; счётчики `source_revisions` дополнительно отражают изменения области. Полный хеш ratings включает также каталог, фактические оценки, версии результатов и ближайший временной переход, поэтому одной ревизии каталога недостаточно для его подмены.

## Отбор и преобразование

- Классический экзамен (`classic`) включён, если московская дата `start_at` находится в периоде и начало уже наступило к `as_of`. Будущий экзамен не попадает в знаменатель заранее. Его ближайшее начало передаётся как `next_exam_start_at`.
- Внешний экзамен (`outside_lms`) включён по своей календарной `exam_date` в периоде. `start_at` может отсутствовать.
- Exams выбирает завершённую попытку с наибольшим `attempt_no`; при одинаковом номере использует больший ID попытки. Незавершённая пересдача оставляет прежнюю завершённую оценку. К выбранной попытке применяется её последняя апелляция.
- Ratings переносит готовое целое `grade` в числовой `score`, `attempt_no>0` — в nullable номер, а `has_appeal` — без изменений. Голоса, пороги, ответы и формула экзамена повторно не рассчитываются.
- Отсутствующая строка результата означает отсутствие завершённого результата. При соединении с участниками core она становится `missing_result=true,score=null`, то есть нулём в среднем E. Присутствующая оценка 0 остаётся настоящим завершённым результатом, а не отсутствием сдачи.
- `account_id` — ID auth. Legacy ID профиля не используется для поиска оценки. В DTO владельца нет ФИО, ответов, токенов или credentials.
- Числовой `exam_id` владельца становится его десятичной строкой в `ExamsSnapshot` и calculate. Сам ID не меняется. Необязательное `exam_name` передаётся в детали calculate; при отсутствующем или пустом поле адаптер выдаёт стабильное название `Экзамен <ID>`. Переименование увеличивает глобальную ревизию экзамена, меняет хеш источника и персонального входа. Уже сохранённый снимок и опубликованная историческая версия остаются неизменными.

Адаптер отвергает чужую организацию/подразделение, другой период/as_of, неверный source/hash, null-массивы, дубли каталога/эффективных результатов, результат без включённого экзамена, включённый будущий classic и несовпадающую московскую дату. Он не подставляет иной источник при отказе проверки.

## Общее содержание и независимая копия

Один экзамен может быть подключён к нескольким подразделениям с одинаковым `exam_id`. Владелец возвращает отдельную каталожную строку и результаты для каждого запрошенного подразделения. Ratings запрашивает одно подразделение и проверяет область каждой строки: оценки, попытки и апелляции ученика в другом подразделении не используются автоматически, даже если совпадает `account_id`.

Независимая глубокая копия exams получает новый `exam_id` и свои подразделения/результаты. Адаптер сохраняет новый ID, не объединяет копию с оригиналом по имени или `origin_exam_id` и не переносит результаты оригинала в пустую копию. Создание/копирование экзамена принадлежит exams.

## Хеш и актуальность

Перед хешированием адаптер устойчиво сортирует каталог, результаты и ревизии. SHA-256 считается по `source_revisions` и семантическому снимку владельца, включая result versions/history generation. Запросный `as_of` исключается из значимых изменений, чтобы само повторное чтение времени не делало неизменённые оценки устаревшими.

`next_exam_start_at` переносится в `ExamsSnapshot.next_transition_at`. Если этот момент наступил до публикации, прежний снимок не публикуется: задание заменяется состоянием `superseded` и требуется явный новый запрос/повтор. При чтении уже опубликованной версии переход отмечает её устаревшей.

Ошибки владельца используют `{status:false,error:<стабильный код>}`. `401` означает служебный ключ, `400` — некорректный запрос, `404` — отсутствующую область, `409` — изменившийся источник, `503` — временную недоступность. HTTP-клиент ratings не пересылает ключ при редиректах и не сохраняет удалённый текст ошибки с персональными данными или credentials.

Транзакция exams делает согласованным только его собственный снимок. Общая транзакция core/homework/tests/exams отсутствует; ratings собирает и сравнивает хеши источников, сохраняет входы и повторно проверяет их перед локальной атомарной публикацией.

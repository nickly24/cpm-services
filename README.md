# CPM backend

Приватный репозиторий backend-сервисов CPM на Go. Frontend находится в отдельном репозитории `nickly24/cpm_front_new` и развёртывается на отдельном сервере.

## Сервисы

Исходники, Dockerfile, миграции, API-контракты и тесты находятся в `services/`:

- `auth` — авторизация и контекст доступа.
- `core` — организации, подразделения, пользователи и группы.
- `bff` — API для frontend.
- `tests` — тесты, попытки и внешние результаты.
- `calculate` — расчёт результатов и фоновые вычисления.
- `cards` — карточки и прогресс обучения.
- `exams` — экзамены.
- `homework` — домашние задания.
- `file-work-service` — обработка файлов домашних заданий.
- `ratings` — рейтинги.
- `attendance` — расписания и посещаемость.
- `uploads` — административные импорты.

Подробности каждого сервиса описаны в его README.

## Ветки

- `dev` — основная ветка разработки.
- `UAT` — версия для приёмочного окружения; имя чувствительно к регистру.
- `prod` — версия для рабочего окружения.

Создание этих веток само по себе не запускает сборку или деплой. CI/CD и production-конфигурация будут настроены отдельно.

## Окружение

В `dev/` находятся существующие локальные Compose-конфигурации, скрипты и мониторинг. Это dev-контур, не готовая production-конфигурация. MySQL, MongoDB и S3 для рабочего окружения остаются внешними.

Секреты, реальные `.env`, локальные runtime-файлы, выгрузки данных и учётные записи не включены в репозиторий. Для настройки окружения используйте `dev/.env.example` и `dev/README.md`; создавайте отдельные значения для каждого окружения. Экспортированные локальные схемы БД также остаются вне Git согласно существующему `dev/.gitignore`.
